# Karwan Noha — Android app

The Android app for **Karwan e Ali Akbar, Dasta e Hussaini — Hussainabad, Malir Karachi**.

## Install

On an Android phone, open the Karwan e Ali Akbar website and tap **Get the Android app**, or download the latest version directly:

**[Download the latest app](https://github.com/aasghar110/karwan-noha-releases/releases/latest/download/karwan-noha.apk)**

Android asks once to allow installing from your browser. After that, the app keeps itself up to date.

This repository holds only the finished app. There is no source code here.
